# Changelog

All notable changes to this project are documented here.

## 1.0.0 - 2026-08-24

- Initial public release.
- Added the Neon Tides glass UI and user-supplied looping MP4 background.
- Added Microsoft Store package and executable-signature validation.
- Added loopback-only CDP launch checks and randomized high-port selection.
- Added startup persistence, watchdog recovery, status reporting, and safe
  disable/uninstall commands.
- Added renderer health checks and in-place reinjection after page/target
  recreation.
- Excluded all user media, private paths, screenshots, and runtime results from
  the release.
